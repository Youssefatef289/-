## 2026-04-25 - Restoring Keyboard Accessibility in Legacy Bootstrap Themes
**Learning:** Legacy Bootstrap v4 themes often globally suppress focus indicators using `outline: none !important` to achieve a "clean" look for mouse users, which completely breaks keyboard navigation. Using `:focus-visible` allows for high-contrast accessibility (using brand colors like #d40) while maintaining the desired aesthetic for mouse users. Additionally, in localized RTL landing pages, screen reader metadata (ARIA labels, alt text) must be provided in the native script (Arabic) to ensure a coherent user experience.
**Action:** Identify and replace global `outline: none` rules with surgical `:focus-visible` indicators. Always match focus ring colors to the brand's primary accent color and localize all accessibility strings.
