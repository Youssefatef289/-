## 2025-01-24 - Restoring Focus Visibility and Localized ARIA Labels
**Learning:** Legacy sites often suppress focus outlines (`outline: none`) for aesthetic reasons, which breaks keyboard navigation. Restoring visibility using `:focus-visible` with a high-contrast brand color (e.g., #d40) ensures accessibility without affecting mouse users. Additionally, for RTL/Arabic content, ARIA labels must be localized to the primary language of the content to be meaningful for screen reader users, regardless of the document's root `lang` attribute.
**Action:** Always replace `outline: none` with a targeted `:focus-visible` style that uses a high-contrast accent color from the site's palette. Provide descriptive Arabic `aria-label` attributes for all icon-only interactive elements in Arabic-first landing pages.
