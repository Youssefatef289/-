## 2025-05-22 - Enhanced Accessibility for Contact Forms
**Learning:** In legacy projects (Bootstrap 4.x), form inputs often rely solely on placeholders, which are not accessible. Using `.sr-only` labels and high-contrast `:focus-visible` styles is a low-impact, high-value way to improve a11y without breaking the original design.
**Action:** Always check for semantic labels and clear focus indicators in legacy forms.
